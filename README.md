# Happy 3rd Year, My Love

A scroll-driven anniversary site: a pink sky that changes mood as you scroll, with framed photos (Memories) floating past and a 3D couple (the Flyers) trailing a pink ribbon and pink-and-orange Stardust along a path of climbs, dives, turns and one loop. See `.scratch/anniversary-site/spec.md` for the full plan and `GLOSSARY.md` for the terms.

## Run it

```bash
npm install
npm run dev        # http://localhost:3000, with hot reload
npm run build      # static export into out/
npm start          # serves out/ locally (any static server works)
```

`npm run build` writes a plain static site to `out/`. To put it online, drag the `out/` folder onto Netlify (or any static host). No server is needed.

## Check a moment without scrolling

- `?p=0.4` opens the page at 40% of the scroll. Useful values: `0` dawn, `0.35` bright pink day, `0.7` sunset, `1` deep rose with stars.
- `?debug` shows live progress and how many ScrollTriggers and ticker callbacks exist (it should always say 1 and 1).
- Combine them: `/?p=0.7&debug`.

## Change the photos and captions

Everything lives in `content/memories.ts`. Add, remove or reorder Memories there; left/right placement follows the order automatically.

1. Copy photos into `public/photos/`.
2. `npm run resize-photos` scales them so the longest edge is about 1600 px (phone-friendly). It only touches jpg, jpeg, png and webp.
3. Point each Memory at its file, e.g. `{ src: "/photos/us-at-the-beach.jpg", caption: "…" }`. Set `ratio` (width / height) for landscape (`1.33`) or square (`1`) photos so nothing is cropped.

The placeholder photos are generated by `node scripts/make-placeholders.mjs` and can be deleted once real ones are in.

## The Flyers (the 3D couple)

By default the Flyers are a simple low-poly couple built in code (`lib/flyers.ts`), in flat colours with a pink rim light. To use your own model, drop a binary glTF at `public/models/couple.glb`: no code change is needed.

- Budget: at most 2 MB and 30,000 triangles. Draco or Meshopt compression is not supported.
- Face the model along +x (to the right) with +y up. It is scaled to fit and centred automatically, and it keeps its own colours (a soft pink rim is added to each standard material).
- A missing, oversized, over-budget or broken file quietly falls back to the built-in couple.

The route they fly is the list of turns at the top of `lib/route.ts` (`TURNS` for wide screens, `PORTRAIT_TURNS` for phones held upright). Edit those to change the flight.

## Notes

- The handwriting is Pinyon Script (SIL Open Font License; licence in `lib/fonts/Pinyon-Script-OFL.txt`), stored in `lib/fonts/pinyon.ts` as the real letter outlines plus a derived pen path for each letter, so text can write itself on while always showing the genuine Pinyon letters. Nothing loads from a CDN or font service. It covers Latin letters, digits and common punctuation and accents only; to change the font or add characters, run `npm run make-script-font -- path/to/Font.ttf` (it regenerates the file and reports any letter its pen path does not fully cover).
- Dependency versions are pinned exactly (see `.npmrc`).
